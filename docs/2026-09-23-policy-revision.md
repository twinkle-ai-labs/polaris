# 2026-09-23 약관 및 화면 정비

## 문서

물타기 계산기·Pocket PDF의 각 11개 언어와 환율 계산기의 한국어 약관·개인정보 처리방침, 총 46개 문서를 정비했다. 사용자 지시에 따라 모든 내용을 제1판에 통합하고 시행일을 2026-09-23으로 통일했다. 제2판이나 시행 예정 공지는 없다.

광고 정보 처리와 동의 선택, 구매·복원·환불, 기기 데이터와 내보낸 사본의 삭제, 문의 처리 절차를 보완했다. 물타기 계산기의 목표 평단가 계산과 무료 종목 한도를 설명했다. 한국어 문체를 다듬고 모든 언어에서 겹화살표 인용부호를 제거했다.

## 화면

- 세 앱의 최신 공식 Play 아이콘을 적용했다.
- 앱 순서를 물타기 계산기 → Pocket PDF → 환율 계산기로 통일했다.
- 본문 행간과 문단 간격을 줄이고 섹션 제목 위 여백을 2rem으로 조정했다. 섹션 사이 구분선은 없다.
- Home과 동일한 헤더 스크롤 진행선 및 전환 효과를 적용했다.
- 미래 판본의 과거 문서 오표기를 수정하고, 향후 개정 공지에서 해당 판본으로 이동할 수 있게 했다.

## 검증

전체 정적 빌드, 문서·번역 구조 검사, 공지 검사, 검사기 회귀 테스트 4건을 통과했다. 46개 문서가 현행 제1판이고 이전·예정 판본이 없음을 확인했다. 아이콘은 앱 원본과 바이트 단위로 일치하며, 로컬 브라우저에서 문구·레이아웃·헤더 동작을 확인했다.

검사기는 일관성을 확인하며 법적 적정성을 인증하지 않는다. 관할별 추가 검토 사항은 `scripts/verify-docs.mjs`의 검토 대장에 유지한다. 앱 번들 사본과 앱 출시는 이번 웹 배포에 포함하지 않는다.
